# セキュリティ境界

この公開版は、合成データによる参照PoCです。セキュリティ認証、第三者ペネトレーションテスト、顧客本番での安全性保証を受けた製品ではありません。

## 実装で守る境界

- 本人はHTTP認証状態または既存MCPの検証済み状態から受け取り、ツール引数のuser/subを使用しない。
- 検索、IDによる本文取得、前後の会話、期間取得で、現在の参加権限と利用許可を再評価する。
- キーワード・意味検索とも、許可したルームのデータだけを検索対象へ取り出す。LLMに渡してから後で隠す方式にしない。
- 同じルームの前後会話だけを展開する。返信先の別ルームを無認可でたどらない。
- 検索対象を承認済みgroupに限定し、DM・My Chat・未承認ルームは取り込みから除外する。
- 認証や現在参加を確認できなければ停止し、古い権限キャッシュで継続しない。
- gatewayは専用audienceのRS256署名・issuer・時刻・5分以内の有効期間を確認する。demo cookieはgatewayでは使用しない。
- デモDBと実データ用DBを起動時に区別する。デモ用変更APIと外部Webhookによる実データ受入は実データモードから分離する。
- JSON解析前の受信量制限、Host制限、他originからの変更要求拒否、no-store、CSP、HTMLエスケープを適用する。
- アップストリームのエラー本文、OAuthトークン、検索本文を監査ログへ書かない。

## 取り消せるもの・取り消せないもの

退室や利用停止後の新たな検索・本文取得は拒否します。ただし、すでに利用者が見た画面、保存したコピー、ChatGPTへ渡した文章を回収することはできません。ブラウザ画面は利用者切替時に本文を消しますが、記憶・スクリーンショット等まで制御するものではありません。

現在参加しているなら参加前の履歴も許可するというPoC仕様です。参加期間単位の権限制御が必要なら履歴情報の入手と認可モデルを追加します。

## 更新・削除・保持

確認できた削除は、検索用本文・参照・Embeddingを消します。物理DBファイル、WAL、レプリカ、バックアップ、GCS原本の保持は別途設定が必要です。原本を無条件で永久保存する方針ではありません。

Chatworkで削除された過去の発言を常に即時検知できるとは限りません。特にIDなし履歴は、次回の完全スナップショット照合まで状態を確認できない場合があります。「現在の権限確認」と「本文の現時点での存在確認」を混同しません。

## 秘密情報

公開リポジトリには実トークン・秘密鍵・顧客CSV・実DBを入れません。独立gatewayの参考認証ファイルは、既存の秘密管理からマウントして読み取ります。読み取れる主体を限定し、平文の出力や公開ログを避けます。実Google Workspace認証、Secret Manager連携、OAuth refreshは既存PoC側の責務です。

## LLMと外部通信

モデルへ返す本文は信頼できない資料として扱います。本文中の「他のルームを検索しろ」「秘密を送信しろ」等を権限根拠にしません。MCPには書き込み・任意SQL・任意URL取得を公開しません。

この検索エンジンはOpenAI APIを呼びません。任意の意味検索モデルは初回取得時に外部通信します。取得後のEmbeddingはローカルです。ChatGPTから利用する場合は、MCP応答として許可済み本文がChatGPTへ渡るため、顧客のAI利用方針・契約・データ所在地を別途確認してください。

## 本番化前の必須確認

既存のGoogle本人確認とChatworkアカウント対応、allow-list無効化の伝播、ロールの変更、API制限、収集担当者の退室、秘密の更新、失敗時の再処理、バックアップ復元、保持期限、負荷・同時更新、監視通知を検証します。依存パッケージとモデルの脆弱性・ライセンスも導入時点で見直します。
