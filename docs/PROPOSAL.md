# 提出用：既存Chatwork検索PoCへの拡張案

以下は公開実装を添えて説明するための案です。実行結果・費用・期間を確認してから案件へ提出してください。本番経験や顧客環境での実績を、この合成データのデモで代替して主張しません。

---

募集内容を拝見し、既存のChatGPT Business／MCP／ユーザー別Chatwork OAuthを維持したまま、過去ログ検索を追加する構成を検討しました。構成案だけでなく、権限制御付き履歴検索の公開参照実装を作成しています。

## 実現したい利用体験

社員がChatGPTに「以前の契約条件はどのような経緯で決まったか」と尋ねた際に、閲覧してよいルームの過去・最新の発言から、日時・発言者・根拠を確認できる形で情報を取得することを中心に据えています。

検索精度だけでなく、古い検討案と現在の決定を区別できること、検索結果の本文を開く際にも権限を確認すること、取り込み期間や同期不足を隠さないことを重視しています。

## 追加する構成

過去ログは管理者エクスポートから取得し、最新ログはAPIによる重複取得で同期します。対象グループのデータを正規化して保存し、キーワード検索・意味検索・日時等の絞り込みをMCPの背後へ追加します。

既存の本人確認、ユーザー別Chatwork OAuth、Firestore allow-listは原則引き継ぎます。現在参加しているルームと会社が承認した対象グループの両方を満たす範囲だけ検索し、IDによる本文取得や前後の会話でも同じ認可を行います。

Google Cloudでは既存Cloud Runを維持し、Cloud Storageによる履歴受領、Cloud SQL等の検索・保存基盤、Cloud Run Jobsによるインポート・同期を追加する案を第一候補とします。最終的な索引方式は、実データ量と日本語の検索例を確認して決定します。

## 公開実装で確認できること

合成データで、過去と最新の検索、営業・開発の権限差、退室後の直接取得拒否、CSVの再実行・更新、同期の不足検出、公式MCPツールの接続を評価できます。日本語のデモ画面、起動手順、テスト、既存PoCへの統合説明を同梱しています。

この公開実装は、貴社の実Chatwork・Google Workspace・ChatGPT Business・GCPへ接続したものではありません。実環境での確認が残る箇所は、検証記録に分けています。

## 最初に確認したいこと

実エクスポートに安定したメッセージIDがあるか、編集・削除がどのように表現されるかを確認します。IDのない履歴を、日時と本文だけで誤って同一視しないためです。また、APIの最新100件や再送のないWebhookだけで全履歴の無欠損同期を保証することは避け、再エクスポートによる照合・補修を設計します。

既存コード・匿名化した実CSVサンプル・利用者数／ルーム数／発言量・実際の質問例を確認し、同期目標と削除反映の許容時間を合意したうえで、詳細設計と簡易PoC実装・動作確認へ進める想定です。

## 今回の納品範囲として合意するもの

現状確認、構成・データ形式の設計、限定した実データ範囲の履歴取り込み、検索、最新同期、ユーザー／ルーム認可、既存MCPへの統合、権限差・退室・更新・削除・再実行の動作確認、運用と本番移行時の残件整理を対象とします。

添付ファイル本文検索、自動エクスポート取得、全履歴の完全保証、本番HA、第三者セキュリティ監査、無期限保守は、この簡易PoCへ無条件に含めるものではありません。
