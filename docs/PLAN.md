# 実装計画と現在位置

最終目標は、募集者が「既存PoCを残したまま、権限を維持して過去を探せる」と判断できる実物を提示することです。機能数や書類の量を目的にしません。

## 計画を先に置いた記録

最初のコミット `24c6d87eec830266337ecae1863193ed4cd41f51` に、日本語の目的・ファイルマップ・実装計画を置きました。その後に本体を追加しています。初期の細かなモジュール案は、実装上の責務を保ちながら `core.py` などへ整理しました。現在の正しい配置は [FILEMAP.md](FILEMAP.md) です。

## 対象としないもの

顧客の実データ、本番OAuth一式、Firestoreの実接続、顧客Cloud Runへのデプロイ、ChatGPT Business実アカウントでの検収は受領後の統合作業です。公開PoCの完成と、顧客環境への導入完了を混同しません。

## PoCの受け入れ条件

| 利用場面 | 確認するもの |
|---|---|
| 古い経緯を探す | 2023年の発言と最近の別案件を日付・情報源で区別できる |
| 別の社員が同じ語を検索 | 営業には開発内部予算が表示されない |
| 一度表示した発言のルームを退室 | 新規検索だけでなくID直接取得・期間取得も拒否される |
| 同じCSVを再投入 | 重複が増えない。誤った行がある場合は途中反映しない |
| 同期停止・大量投稿 | 取得漏れの可能性を隠さず、ルームの状態に残す |
| 期間全体を確認 | 上位検索だけで済ませず、ページを最後まで取得できる |
| 別の人が再現 | READMEから起動し、テスト・画面操作を再実行できる |

## 次に進む条件

CIのテスト成功は、本番の安全性や検索精度の保証ではありません。顧客統合へ進むには、実CSVの構造、既存認証のひもづけ、対象規模、更新・削除反映の要求、保持期間を確認します。新しい根拠で前提が変わった場合は、この計画と [LESSONS.md](LESSONS.md) を更新し、古い判断に従って機能を増やし続けないこととします。
